# Codex Project Instructions

At the beginning of every new Codex session in this repository:

1. Read `CLAUDE.md` completely.
2. Treat `CLAUDE.md` as the primary source for stable project architecture, coding conventions, commands, and development rules.
3. Read `PROJECT_STATUS.md` to understand the current implementation status, recent changes, known issues, pending work, architectural decisions, and previous approaches that should not be repeated.

After completing an important feature, bug fix, API/database change, architectural decision, authentication change, deployment change, or meaningful project status change, update `PROJECT_STATUS.md`.

Do not duplicate the full contents of `CLAUDE.md` or `PROJECT_STATUS.md` here.
